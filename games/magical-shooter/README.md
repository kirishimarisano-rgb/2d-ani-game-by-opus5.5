# 星織魔法少女 艾菈 ☆ STARLIGHT AIRA

一款**二次元像素風縱向捲軸彈幕射擊**網頁遊戲。
你將操控原創魔法少女「艾菈（Aira）」，在星夜中擊退夜蝠精、暗影妖精、水晶魔像，最後迎戰兩階段 Boss「夢魘女王 諾克緹娜」。

## 📖 遊戲說明

- **血量**：艾菈有 5 顆愛心，被敵彈或敵人撞到會失去 1 顆，並有 2 秒無敵（角色閃爍）。愛心歸零即 Game Over。
- **判定點**：只有角色中心的小點會被打中，按住 Shift 可以看到它，擦過子彈（擦彈）還會加分。
- **火力等級（P★）**：撿「P」道具最多升到 4 級：雙發 → 斜射 → 追加星之使魔 → 使魔發射追蹤彈。被擊中會降 1 級。
- **星爆炸彈**：消除畫面上所有敵彈並對所有敵人造成大傷害，發動期間無敵。初始 3 發、最多 5 發。
- **最高分**：自動儲存在瀏覽器（localStorage），標題畫面與遊戲中都會顯示。
- **周目制**：擊敗 Boss 後會進入下一周目（LOOP 2、3…），敵人血量、彈速、彈量逐步提升，分數倍率也跟著提高。

### 道具

| 道具 | 效果 |
| --- | --- |
| 🟥 P | 火力 +1（滿級時 +1000 分） |
| ❤ 愛心 | 回復 1 點血量（滿血時 +2000 分） |
| 🟦 B | 炸彈 +1（滿時 +1500 分） |
| ⭐ 星星 | +500 分 |

角色移到畫面上方時，會自動吸取畫面上所有道具。

### 敵人

| 敵人 | 特徵 |
| --- | --- |
| 夜蝠精 | 成群出現（縱列蛇行、V 字編隊、側邊橫掃），發射瞄準彈 |
| 暗影妖精 | 飛到定點後連續發射環狀彈幕，接著離場 |
| 水晶魔像 | 高血量重裝敵人，發射五向扇形彈與大型紅彈 |
| **Boss：夢魘女王 諾克緹娜** | 第一階段：三向旋轉星雲、瞄準扇形 + 環形彈。血量過半進入**第二階段（覺醒）**：換色、雙重反向螺旋、血紅之雨 + 狙擊、夢魘之花 |

## ✨ 特色

- 單一 `index.html`，純 HTML + JavaScript + Canvas，**不使用任何外部圖片或音檔**
- 所有像素圖（主角、敵人、Boss、道具、子彈）都是以字元陣列定義像素、由程式即時繪製；Boss 採左半邊定義後鏡射
- 音效與背景音樂全部以 **Web Audio API** 即時合成（道中曲與 Boss 曲各一首的晶片音樂編曲器）
- 受擊閃爍、畫面震動、爆炸粒子與衝擊波、擦彈火花、道具吸取
- 支援手機觸控操作、高 DPI 螢幕、視窗縮放；切到其他分頁時自動暫停

## 🧑‍🎨 原創角色

「艾菈（Aira）」是本作原創的魔法少女：薰衣草銀色長髮、金色星形髮飾、白色與薄荷色洋裝、粉紅緞帶。Boss「諾克緹娜」同為原創角色。本作未使用任何既有作品的角色。
