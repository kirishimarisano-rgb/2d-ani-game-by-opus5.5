# 第二款遊戲：三個概念與手感原型

這裡是星屑遊樂場第二款遊戲的**前期探索**。三個概念類型各不相同，每個都做了一個只有一個場景的可玩原型，重點是**移動與攻擊的手感**。每個原型右側都有調參面板，可以即時調整並比較。

| --- | --- | --- | --- |
| 類型 | 橫向動作平台（銀河惡魔城 Lite） | 俯視角動作 Roguelite | 清版格鬥（Beat 'em up） |

| 主角 | 巫女「緋鈴」＋神樂鈴杖 | 見習魔女「茴香」＋園藝鐮刀 | 街頭少女「阿芒」＋拳腳 |

| 最強的賣點 | 鈴聲隨連段譜成旋律的揮擊 | 完美閃避＋撞牆連鎖的爽快感 | 浮空追擊＋衝擊格的動畫演出 |

## 概念 A：《月下神樂》— 橫向動作平台

> 月夜的山中神社，巫女緋鈴揮舞會響的神樂鈴杖，驅散附在神社器物上的妖怪。

**核心玩法循環**
探索相連的神社區域（鳥居參道 → 竹林 → 本殿 → 地下祭壇）→ 遇到妖怪與地形挑戰 → 擊敗區域的守護妖（Boss）→ 學會新的「神樂之舞」→ 回頭打開先前過不去的路，找到隱藏的御守與鈴鐺。

**成長系統**
- **能力＝地圖鑰匙**：二段跳 → 空中衝刺 → 下劈彈跳 → 壁跳 → 袖子滑翔。
- **御守裝備格**：例如「第三擊變成迴旋」「鈴聲命中回復靈力」「打擊停頓變長、傷害提高」。
- **鈴鐺收集**：提高最大 HP 與靈力上限；靈力用來施放「結界」。

**手感重點**
- 跳躍要「精準又寬容」：可變跳躍高度、下落比上升快、頂點滯空、土狼時間、跳躍輸入緩衝。
- 揮杖的節奏：三段連擊，**每一下命中的鈴聲沿五聲音階往上爬**，連段本身就是一段旋律。
- 下劈彈跳：空中踩著敵人不落地，並恢復二段跳與衝刺。
- 打擊停頓、受擊者抖動、刀光殘影、擊退與自身反衝的份量。

**畫面風格**
夜色藍紫＋朱紅＋燈籠金的 16 色調色盤；超大月亮、遠山、五重塔、樹林的多層視差；飄落的櫻花與靈火。角色 16×26 像素，身體分件動畫，鈴杖與兩條緞帶由程式即時繪製（緞帶有繩索物理）。

**原型內容**：一條約三個畫面寬的神社參道，包含高台、單向木板、凹地、需要二段跳的高柱；稻草人訓練靶、提燈妖（飛行）、唐傘妖（跳躍），被打倒會重生。

## 概念 B：《溫室魔女的剪定日》— 俯視角動作 Roguelite

> 魔法溫室的植物全暴走了，見習魔女茴香拿起園藝鐮刀，一間一間修剪回來。

**核心玩法循環**
進入溫室的一個房間（戰鬥／寶箱／商店／泉水）→ 清完敵人 → 從三個「祝福」中選一個 → 選擇下一個房間的岔路 → 樓層 Boss（巨大食人花）→ 死亡或通關後回到溫室小屋，用收集的種子做永久強化，再挑戰下一輪。

**成長系統**
- **局內：祝福**。本原型已可試玩三種——荊棘衝刺（翻滾留下傷人的藤蔓）、新月剪（第三擊射出劍氣）、花粉爆裂（擊倒時爆炸，可連鎖）。
- **祝福組合**：例如「荊棘衝刺＋花粉爆裂」→ 藤蔓開花爆炸，讓每一輪的打法都不同。
- **局外：溫室小屋**。用種子種出永久強化（最大 HP、翻滾次數、開局祝福），並解鎖新武器（剪刀雙刀、澆水壺槍…）與新的祝福池。

**手感重點**
- 八方向移動的加減速、轉身加成，以及翻滾的「爆發曲線」與無敵時段。
- **完美閃避**：翻滾剛開始時與攻擊擦身而過，觸發子彈時間（只有世界變慢）。
- 三段揮砍（第三段大迴旋）、揮完按住攻擊蓄力的迴旋斬。
- 把敵人打飛去撞牆、撞其他敵人的連鎖傷害；孢子彈可以直接斬斷。

**畫面風格**
白天的暖色溫室：陶土、嫩葉、玻璃青的 16 色調色盤；俯視 3/4 視角、斜射的抖動光帶。角色 16×22 像素，有前／後／側三個方向，腳步與鐮刀由程式繪製；刀光是嫩葉色的弧形殘影並飛散葉片。

**原型內容**：一間有花台、花盆（可打破、偶爾掉出回復道具）的溫室房間；南瓜人偶訓練靶、芽芽史萊姆（跳躍追擊）、棘甲蟲（預告後衝鋒，撞牆會暈眩）、孢子菇（發射孢子彈），無限波次。

## 概念 C：《夜市拳姬》— 清版格鬥

> 夜市收攤前，一群穿布偶裝的混混跑來搗亂，愛吃芒果冰的阿芒用拳腳清場。

**核心玩法循環**
沿著夜市街道推進 → 一波波布偶混混出現 → 用連段、浮空追擊、投技與場景物件（招牌、攤車、塑膠椅）清場 → 街尾 Boss（夾娃娃機大王、珍奶巨人…）→ 關卡評分（連段數、時間、受傷）→ 下一條街。可以支援雙人同樂。

**成長系統**
- **招式解鎖樹**：用關卡評分換新招（投技、蓄力拳、空中連段、反擊技）。
- **夜市小吃增益**：每關開始前買一樣小吃，只維持一關（芒果冰＝攻擊提升、大腸包小腸＝HP 回復…）。
- **角色等級**：提高 HP 與特殊技量表。

**手感重點**
- 四段連擊的節奏與「接招時機」，每一招自動往前踏步追著敵人打。
- 上勾拳打飛後在空中繼續追打：浮空重力、追擊托高、追擊上限都能調。
- **打擊停頓隨連段累加**（越打越重）、終結技的衝擊格（黑白剪影閃格）。
- 群戰節奏：同一時間只有少數敵人會出手（出手權）；熊熊保鑣出招時有霸體，要學會閃開或先發制人。

**畫面風格**
霓虹粉＋青＋燈籠黃的夜市 16 色調色盤；條紋遮雨棚、霓虹招牌、燈籠串、水窪倒影，前景路燈柱營造縱深。角色採「骨架＋像素線條四肢」：頭與身體是像素圖，四肢由帶外框的像素線條即時繪製，每個出拳踢腿都能用角度擺姿勢並平滑補間，敵人共用骨架、換上布偶裝。

**原型內容**：約三個畫面寬的夜市街道；練習用兔兔布偶（不會攻擊、可以浮空追擊）、兔兔混混、熊熊保鑣（霸體），會從畫面兩側持續補充。

## 原型共通規格

- **固定低解析度整數放大**：遊戲畫面固定 320×180，依視窗大小取「整數倍」放大（2×、3×、4×…），像素永遠方正。
- **限定 16 色調色盤**：每個原型各自一組 16 色；所有繪圖函式只接受調色盤索引，半透明與淡出效果都改用色階與有序抖動。冒煙測試會逐一檢查畫面上的每個像素都屬於調色盤。
- **角色有基本動畫**：待機、移動、跳躍／翻滾、攻擊、受擊、倒地等。
- **所有角色與美術皆為原創**，全部以字元陣列或程式繪製；音效以 Web Audio 即時合成。
- **操作**：鍵盤、手把（標準配置），觸控裝置會出現虛擬搖桿與按鈕。

## 調參面板怎麼用

- **即時生效**：拖動滑桿或直接輸入數字。修改過的項目會標記粉紅圓點，**雙擊名稱**還原單項。
- **風格預設**：每個原型都有數個預設風格，其中「**無特效對照組**」會關掉打擊停頓、震動、閃白等，最能感受「手感」差在哪裡。
- **A/B 比較**：把兩組參數分別存到 A、B，來回切換比較。
- **複製／貼上**：把修改過的參數以 JSON 複製出來——**覺得對的手感，可以直接貼給我**，正式開發就以它為基準。
- **除錯與檢視**：遊戲速度（慢動作）、顯示判定框（H 鍵）、顯示即時數值；P 暫停、N 逐格播放、R 重置場景、` 鍵開關面板。
- 參數會自動記在瀏覽器裡，下次打開還在。
