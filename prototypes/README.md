# 三款完整遊戲：月下神樂／溫室魔女的剪定日／夜市拳姬

這三款一開始是「第二款遊戲」的三個手感原型，現在都已經是可以從頭玩到結局的完整遊戲。網址維持不變：

- 《月下神樂》 <https://kirishimarisano-rgb.github.io/2d-ani-game-by-opus5.5/prototypes/moon-kagura/>
- 《溫室魔女的剪定日》 <https://kirishimarisano-rgb.github.io/2d-ani-game-by-opus5.5/prototypes/greenhouse-witch/>
- 《夜市拳姬》 <https://kirishimarisano-rgb.github.io/2d-ani-game-by-opus5.5/prototypes/night-market-brawler/>

三款都有：標題畫面、地圖或據點、多個關卡與 Boss、成長系統、商店、劇情對話、每個場景各自的背景音樂，以及自動存檔（存在瀏覽器的 localStorage，標題畫面可以刪除存檔）。原型時期的調參面板也都保留著。

## 《月下神樂》MOONLIT KAGURA — 橫向動作平台（銀河惡魔城 Lite）

> 月夜的山中神社，巫女緋鈴揮舞神樂鈴杖，穿過四個區域驅散妖怪，找回被蝕影吞噬的月亮。

- **四個區域與守護妖**：鳥居參道（大提燈・火袋）→ 竹林小徑（疾風・鎌鼬）→ 本殿迴廊（千年白狐）→ 地下祭壇（月蝕大蛇）。從神社地圖選擇區域，可以回到打過的區域。
- **能力＝鑰匙**：打倒守護妖學會新的「神樂之舞」——下劈彈跳、二段跳、壁跳。有些金鈴要學會後面的能力才拿得到。
- **收集與成長**：每個區域藏著 3 個金鈴，每 3 個最大體力 +1；寶箱裡的御守、狸貓茶屋賣的御守（共 8 種）可以裝備 2 個改變打法。
- **靈力**：打中妖怪累積靈力，點按放出「鈴祓」，按住回復體力。
- **地形**：單向木板、會崩落的地板、尖刺、風鈴（下劈彈跳的踏點）、太鼓（彈跳台）、可以打破的牆，以及點亮後當作檢查點的石燈籠。
- **操作**：方向鍵移動、Z 跳躍、X 攻擊（↑ 上挑、空中 ↓ 下劈）、C 衝刺、V 靈力、Esc 暫停。

## 《溫室魔女的剪定日》PRUNE & BLOOM — 俯視角動作 Roguelite

> 魔法溫室的植物全都暴走了，見習魔女茴香拿起園藝工具，一間一間修剪回來。

- **三層樓**：苗圃區（芽芽史萊姆王）→ 藥草園（女王蜂）→ 玻璃穹頂（巨大食人花 拉芙蕾西亞）。每層 6～7 個房間，每一輪的房間與獎勵都不同。
- **選門**：清完房間後從兩三扇門選下一間，門上的牌子寫著房間種類（戰鬥、強敵、商店、泉水、守護者）與獎勵（祝福、稀有祝福、祝福升級、金幣、種子、回復）。
- **16 種祝福**：最多升到 Lv3，可以重擲；組合會大幅改變打法（荊棘衝刺、新月剪、花粉爆裂、蜂蜜護盾、蒲公英……）。
- **局外成長**：倒下或通關後帶著種子回到溫室小屋，在苗圃種出永久強化（生命之根、翻滾之葉、起始花苞、幸運草盆、零錢罐、不死鳥花），在武器架解鎖雙刃剪與澆水壺。
- **手感**：翻滾剛開始時與攻擊擦身而過＝完美閃避（子彈時間）；揮完按住攻擊蓄力；把魔物打去撞牆、撞其他魔物。
- **操作**：方向鍵移動、Z 攻擊（按住蓄力）、X／Space 翻滾、滑鼠左鍵攻擊右鍵翻滾、Esc 暫停。

## 《夜市拳姬》NIGHT MARKET BRAWLER — 清版格鬥

> 夜市收攤前，一群穿布偶裝的混混跑來搗亂。愛吃芒果冰的阿芒從入口牌樓一路打到廟口廣場。

- **四條街道**：入口牌樓（兔兔老大）→ 小吃街（珍奶巨人）→ 遊戲攤（夾娃娃機大王）→ 廟口廣場（熊貓大仙）。每條街有 3～4 個戰鬥區，進入時鏡頭鎖定，清完所有波次才能前進。
- **敵人**：兔兔混混、熊熊保鑣（出招時霸體）、狗狗投手（從遠處丟東西）、貓咪飛踢手（遠距離飛撲），守護者各有不同的招式與生氣後的變化。
- **招式**：四段連擊與上勾拳浮空追擊、飛踢、奔跑滑壘、旋風腿；走進暈眩的敵人會抓住（膝擊或丟出去砸倒一排）；塑膠椅可以撿起來揮或丟；紙箱與垃圾桶打破會掉出食物和金幣；量表滿了放出必殺技「芒果冰暴風」。
- **評價與修行**：通關依接關、受傷、時間、最高連段評為 S／A／B／C，換成修行點數；在修行場學新招（鐵布衫、空中連擊、蓄力重拳、旋風腿・改、過肩摔、滑壘上挑、氣勢），也可以用金幣繳學費換點數。
- **小吃攤**：用金幣買一份小吃，下一條街生效（芒果冰攻擊提升、烤香腸體力提升、珍珠奶茶量表加速、臭豆腐臭味傷害、炸雞排區間回復、糖葫蘆加速）。
- **接關**：倒下可以原地接關（評價會降低），倒數結束回到夜市地圖。打倒熊貓大仙會看到結局。
- **操作**：方向鍵移動（上下＝往深處，連按兩下奔跑）、Z 攻擊、X／Space 跳躍、C 旋風腿、V 必殺、Esc 暫停。

## 概念 A：《月下神樂》— 橫向動作平台

> 月夜的山中神社，巫女緋鈴揮舞會響的神樂鈴杖，驅散附在神社器物上的妖怪。

**核心玩法循環**
探索相連的神社區域（鳥居參道 → 竹林 → 本殿 → 地下祭壇）→ 遇到妖怪與地形挑戰 → 擊敗區域的守護妖（Boss）→ 學會新的「神樂之舞」→ 回頭打開先前過不去的路，找到隱藏的御守與鈴鐺。

**成長系統**
- **能力＝地圖鑰匙**：二段跳 → 空中衝刺 → 下劈彈跳 → 壁跳 → 袖子滑翔。
- **御守裝備格**：例如「第三擊變成迴旋」「鈴聲命中回復靈力」「打擊停頓變長、傷害提高」。
- **鈴鐺收集**：提高最大 HP 與靈力上限；靈力用來施放「結界」。

**手感重點**
- 跳躍要「精準又寬容」：可變跳躍高度、下落比上升快、頂點滯空、土狼時間、跳躍輸入緩衝。
- 揮杖的節奏：三段連擊，**每一下命中的鈴聲沿五聲音階往上爬**，連段本身就是一段旋律。
- 下劈彈跳：空中踩著敵人不落地，並恢復二段跳與衝刺。
- 打擊停頓、受擊者抖動、刀光殘影、擊退與自身反衝的份量。

**畫面風格**
夜色藍紫＋朱紅＋燈籠金的 16 色調色盤；超大月亮、遠山、五重塔、樹林的多層視差；飄落的櫻花與靈火。角色 16×26 像素，身體分件動畫，鈴杖與兩條緞帶由程式即時繪製（緞帶有繩索物理）。

**原型時期的內容**：一條約三個畫面寬的神社參道，包含高台、單向木板、凹地、需要二段跳的高柱；稻草人訓練靶、提燈妖（飛行）、唐傘妖（跳躍），被打倒會重生。

## 概念 B：《溫室魔女的剪定日》— 俯視角動作 Roguelite

> 魔法溫室的植物全暴走了，見習魔女茴香拿起園藝鐮刀，一間一間修剪回來。

**核心玩法循環**
進入溫室的一個房間（戰鬥／寶箱／商店／泉水）→ 清完敵人 → 從三個「祝福」中選一個 → 選擇下一個房間的岔路 → 樓層 Boss（巨大食人花）→ 死亡或通關後回到溫室小屋，用收集的種子做永久強化，再挑戰下一輪。

**成長系統**
- **局內：祝福**。本原型已可試玩三種——荊棘衝刺（翻滾留下傷人的藤蔓）、新月剪（第三擊射出劍氣）、花粉爆裂（擊倒時爆炸，可連鎖）。
- **祝福組合**：例如「荊棘衝刺＋花粉爆裂」→ 藤蔓開花爆炸，讓每一輪的打法都不同。
- **局外：溫室小屋**。用種子種出永久強化（最大 HP、翻滾次數、開局祝福），並解鎖新武器（剪刀雙刀、澆水壺槍…）與新的祝福池。

**手感重點**
- 八方向移動的加減速、轉身加成，以及翻滾的「爆發曲線」與無敵時段。
- **完美閃避**：翻滾剛開始時與攻擊擦身而過，觸發子彈時間（只有世界變慢）。
- 三段揮砍（第三段大迴旋）、揮完按住攻擊蓄力的迴旋斬。
- 把敵人打飛去撞牆、撞其他敵人的連鎖傷害；孢子彈可以直接斬斷。

**畫面風格**
白天的暖色溫室：陶土、嫩葉、玻璃青的 16 色調色盤；俯視 3/4 視角、斜射的抖動光帶。角色 16×22 像素，有前／後／側三個方向，腳步與鐮刀由程式繪製；刀光是嫩葉色的弧形殘影並飛散葉片。

**原型時期的內容**：一間有花台、花盆（可打破、偶爾掉出回復道具）的溫室房間；南瓜人偶訓練靶、芽芽史萊姆（跳躍追擊）、棘甲蟲（預告後衝鋒，撞牆會暈眩）、孢子菇（發射孢子彈），無限波次。

## 概念 C：《夜市拳姬》— 清版格鬥

> 夜市收攤前，一群穿布偶裝的混混跑來搗亂，愛吃芒果冰的阿芒用拳腳清場。

**核心玩法循環**
沿著夜市街道推進 → 一波波布偶混混出現 → 用連段、浮空追擊、投技與場景物件（招牌、攤車、塑膠椅）清場 → 街尾 Boss（夾娃娃機大王、珍奶巨人…）→ 關卡評分（連段數、時間、受傷）→ 下一條街。可以支援雙人同樂。

**成長系統**
- **招式解鎖樹**：用關卡評分換新招（投技、蓄力拳、空中連段、反擊技）。
- **夜市小吃增益**：每關開始前買一樣小吃，只維持一關（芒果冰＝攻擊提升、大腸包小腸＝HP 回復…）。
- **角色等級**：提高 HP 與特殊技量表。

**手感重點**
- 四段連擊的節奏與「接招時機」，每一招自動往前踏步追著敵人打。
- 上勾拳打飛後在空中繼續追打：浮空重力、追擊托高、追擊上限都能調。
- **打擊停頓隨連段累加**（越打越重）、終結技的衝擊格（黑白剪影閃格）。
- 群戰節奏：同一時間只有少數敵人會出手（出手權）；熊熊保鑣出招時有霸體，要學會閃開或先發制人。

**畫面風格**
霓虹粉＋青＋燈籠黃的夜市 16 色調色盤；條紋遮雨棚、霓虹招牌、燈籠串、水窪倒影，前景路燈柱營造縱深。角色採「骨架＋像素線條四肢」：頭與身體是像素圖，四肢由帶外框的像素線條即時繪製，每個出拳踢腿都能用角度擺姿勢並平滑補間，敵人共用骨架、換上布偶裝。

**原型時期的內容**：約三個畫面寬的夜市街道；練習用兔兔布偶（不會攻擊、可以浮空追擊）、兔兔混混、熊熊保鑣（霸體），會從畫面兩側持續補充。

## 共通規格

- **固定低解析度整數放大**：遊戲畫面固定 320×180，依視窗大小取「整數倍」放大（2×、3×、4×…），像素永遠方正。
- **限定 16 色調色盤**：每個原型各自一組 16 色；所有繪圖函式只接受調色盤索引，半透明與淡出效果都改用色階與有序抖動。冒煙測試會逐一檢查畫面上的每個像素都屬於調色盤。
- **角色有基本動畫**：待機、移動、跳躍／翻滾、攻擊、受擊、倒地等。
- **中文也是像素**：對話與選單的中文字先點陣化，再以調色盤顏色描繪（加外框、陰影），不會有平滑字體混在像素畫面裡。
- **音樂**：背景音樂以文字樂譜寫成，由共用的晶片音樂音序器即時合成（方波、三角波、雜訊鼓）。
- **所有角色與美術皆為原創**，全部以字元陣列或程式繪製；音效以 Web Audio 即時合成。
- **操作**：鍵盤、手把（標準配置），觸控裝置會出現虛擬搖桿與按鈕。

## 調參面板怎麼用

- **即時生效**：拖動滑桿或直接輸入數字。修改過的項目會標記粉紅圓點，**雙擊名稱**還原單項。
- **風格預設**：每個原型都有數個預設風格，其中「**無特效對照組**」會關掉打擊停頓、震動、閃白等，最能感受「手感」差在哪裡。
- **A/B 比較**：把兩組參數分別存到 A、B，來回切換比較。
- **複製／貼上**：把修改過的參數以 JSON 複製出來——**覺得對的手感，可以直接貼給我**，正式開發就以它為基準。
- **除錯與檢視**：遊戲速度（慢動作）、顯示判定框（H 鍵）、顯示即時數值、無敵與全解鎖（測試用）；F 凍結畫面、N 逐格播放、M 靜音、` 鍵開關面板。
- 參數會自動記在瀏覽器裡，下次打開還在。
